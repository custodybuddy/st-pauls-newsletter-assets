# assets/ — FROZEN legacy folder

This folder is read-only. It is kept only so image URLs in already-published emails keep resolving on GitHub Pages (`https://custodybuddy.github.io/st-pauls-newsletter-assets/assets/...`).

- Do not edit, rename, move, or delete anything here. GitHub Pages does not redirect moved files, so any change can break images in emails people have already received.
- New work must use `brand/assets/` (icons, banners, illustrations, reference images).
- Icon filenames, roles, and URLs are defined in `brand/resources/icon-map-v4.json`.

See `AGENTS.md` and `README.md` at the repository root.
