# Newsletter Content File (assembly input)

**How to use:** Copy this file to `newsletters/drafting/<year>-<season>/content.md` and fill it in with Kathy's approved copy, word for word. This is the only place wording lives. The HTML is built from it.

- **Include a section:** fill it in.
- **Leave a section out:** delete it. Nothing breaks.
- **Change the order:** move the `## SECTION` blocks up or down. The order in this file is the order in the newsletter. Keep the three **permanent** blocks first (Basics, Greetings and Mission) and last (Footer). Closing Message goes just above the footer.
- **Missing something?** Write `[NEEDS APPROVED COPY]`. Do not guess dates, names or figures.
- Editorial drafting happens in Kathy's template (`kathy-drafting-template.md`). This file is what you paste her approved text into.

Component names match `.claude/skills/st-pauls-newsletter/components.md`.
