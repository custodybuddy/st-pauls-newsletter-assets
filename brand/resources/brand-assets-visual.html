Quick rules

Before you build

  • Use the full image URLEmail images must use absolute .../st-pauls-newsletter-assets/brand/assets/... URLs.
  • Light text on navyWhite headings, #E2E8F0 body, gold or light gold labels.
  • One icon per sectionFollow the icon map; omit the icon rather than substitute.
  • Emphasize sparinglyGold/bold only on names, dates, numbers, calls to action.
  • Table layout, inline stylesNo grid, flexbox or scripts inside the email itself.
  • Keep archive sectionsImprove hierarchy; do not drop sections readers know.
