# Archived St. Paul’s Icons

This folder preserves the previous v4 icon exports and alternate generated
variants moved out of `assets/icons/` on 2026-09-08.

- Files beginning with `_` are the previous canonical v4 exports.
- `*-variant.png` files are alternate generated exports, not production icons.
- Production email work must continue to use the canonical files in
  `assets/icons/` and the manifest in `resources/links/st-pauls-icons-v4.json`.
