# Archive: published issues (read-only)

Every issue here was sent to the church community. Do not edit these files. Use them to keep new issues consistent with the sections and components readers already know, while improving design and visual hierarchy. Structure for new work still comes from `docs/st-pauls-comprehensive-newsletter-template.md`.

## Adding an issue

1. Create `<year>-<season>/<yyyy-mm-month>/`.
2. Save the sent HTML as `newsletter.html`.
3. Add `screenshot.png` (and `screenshot-full.png` for a full-length capture).
4. Add a row to the table above.

## Notes

- Season placement is by publication date. September 2025 is filed under Fall 2025; move it if you count it as Summer.
- Many of these files use the removed `/assets/` image URLs, embedded images, or unbalanced tables. The audit reports them as warnings. Do not copy their markup.
- Design analysis: `resources/archive-review/ARCHIVE-NEWSLETTER-DESIGN-ANALYSIS.md` and `ARCHIVE-NEWSLETTER-PATTERNS-AND-THEMES.md`.
