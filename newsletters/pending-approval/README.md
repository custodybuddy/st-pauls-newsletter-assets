# Pending Approval

Keep exactly one proposed final HTML file here at a time. It is the single candidate waiting for Kathy's approval.

- Build and edit drafts in `newsletters/drafting/`, not here.
- Copy the chosen candidate here only when it is ready for review. Do not edit it in place; make a new version in `drafting/` and swap it in.
- Before moving a file here, run `node scripts/audit-newsletter-repo.js` and complete `newsletter-system/docs/qa-checklist.md`.
- After approval and publication, copy the final file into `newsletters/archive/` (read-only) and clear this folder.

This folder is empty on purpose until an issue is ready for review.
